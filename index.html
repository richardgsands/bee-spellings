    Handwriting checking

    Bumble reads the writing with Claude, which copies the letters exactly as written, so spelling mistakes aren't “auto-corrected”. If Claude can't be reached, Google's free reader is used instead.

    When this is on, a picture of just the written word (no names or anything else) is saved for up to 90 days so we can check how accurately Bumble reads children's writing. Anonymous usage counts (a random device ID and the country/region) are recorded either way.

    Practice

    Voice

    💡 For a much more natural voice, download a free British voice on the iPad: Settings → Accessibility → Read & Speak (or Spoken Content) → Voices → English → English (UK), choose a voice such as Serena or Jamie, and download its Premium (or Enhanced) version. Then reload this page; Bumble picks it automatically.

    If a word is said wrongly, type how it sounds in the word list's Say it as box (e.g. reeding for “reading”).
